Problem Statement

Organizations operate on implicit trust — being inside the network perimeter grants access without additional controls. This enables lateral movement and exploitation of IAM vulnerabilities. The capstone project proposes a technical model to identify access risks and guide their transition to Zero Trust.

Research Contribution

A locally-deployed LLM integrated into a Policy Decision Point (PDP) architecture to:

  • ✓ Automatically assess cloud architectures against Zero Trust principles
  • ✓ Prioritize access risks using contextual severity scoring (0–1 continuous scale)
  • ✓ Generate structured JSON audit reports with DENY/ALLOW policy decisions
  • ✓ Cross-correlate findings across ISO 27001, NIST SP 800-207, DORA & ISO 31000
  • ✓ Produce PlantUML architecture diagrams visualizing hardened configurations
  • ✓ Provide progressive hardening recommendations per component
